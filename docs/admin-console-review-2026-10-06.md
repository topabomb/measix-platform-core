## 发现与修复

每项行为修复先添加最小组件失败测试并观察 Red，再修改实现，最终运行完整 Green。

| 问题 | 修复后的行为 |
| --- | --- |
| 最多 4096 个目录/失效批准项同时渲染 | 合并搜索，每页 25 项；选择跨页保留，翻页回到目录摘要 |
| 服务器空白名单提示要求操作助手开关 | 独立服务器提示，停用使用 enabled；ALL 明示发现可选 |
| 未发现目录就把保留批准项当作删除 | 保留上次定义，显示未核实；完整发现缺失才报删除 |
| 助手名称暂不在 ALL 目录时显示权限错误 | 提示暂不可用并保留名称；超出服务器 ALLOWLIST 才报权限错误 |
| 助手的大目录选择框只能滚动寻找 | 可按名称/确认标签搜索，既有选择不被过滤丢弃，“选择当前工具”仍选完整当前目录 |
| 空白公告能调用 API，最后只显示通用 422 | 标题与正文 trim 后非空才可提交，创建/编辑均保护，提交中禁用重复操作 |
| 设置页将 UNAVAILABLE 当业务文案 | 使用已有中英 Portal 模式标签，部署标识按需展开 |

本轮整体还修复了搜索清除的 null 异常、长 MCP 切换分区后的滚动遮挡和禁用服务器错误要求在线发现。架构文档中“助手空白名单不限制”的过时表述已移除，统一为 ALL 不额外限制、ALLOWLIST 空名单无效。

## 全部 Git 变更复核

| 范围 | 复核方法与结论 |
| --- | --- |
| Architecture | 逐项检查全部 12 份文档 diff；wire/状态/安全 owner 一致，保留 v4、未绑定/不可用/不限制明确；Direct 与未来 Gateway/Workflow 边界一致 |
| OpenAPI、fixtures、摘要 | 检查 required/null/枚举、v4 独立 DTO、新 v5 授权闭合、JCS 向量及 protocol-baseline；canonical fixtures 为唯一跨组件事实 |
| Hub/HTTP | 检查发现的 JSON/SSE/分页/session、响应/工具/超时边界、无工具执行、敏感异常不外泄、来源校验与 CAS、网络 IO 不持事务、保存防伪与 Preview/Publish 共用校验 |
| 投影与持久化 | 检查排序/完整合同 hash、客户端无定义/身份/私有来源、发现事实不计发布差异、停用保留定义、v4 bytes/hash 和重发布；没有迁移或清库 |
| Admin | 检查组件、store、页面、i18n 和全部新增/修改测试；实际浏览器验证模式、失效引用、操作边界和窄屏 |
| 脚本与生成产物 | 检查实际脚本 diff；生成产物通过两轮同源再生逐文件 hash 比对，Ent 另用隔离同版本生成比对，避免把巨大生成 diff 当作人工判断依据 |
| Portal | 全部 5 项变更为生成 Client 类型/schema/来源摘要与交接文档；独立生成、类型/单元/构建及 STANDARD/CUSTOM 浏览器回归，未增加 Admin/执行入口 |

提交前检查所有实际 diff 与新增文件，执行三个仓库 `git diff --check` 和 staged diff 检查；忽略的数据库、凭据、截图、构建和日志不入 Git。逐文件摘要、Red/Green 日志、实际浏览器报告、源码/构建链与提交身份记录在本地 `.artifacts/mcp-tool-governance-verification.json` 和 `.artifacts/admin-review-verification.json`。
